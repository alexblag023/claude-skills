# Скрипты скилла: что делает, что читает, что пишет

Детерминированные гварды протокола. Python 3.11+, **только стандартная библиотека**.

**Общие свойства всех скриптов:**

- нет сетевых обращений, нет внешних утилит, нет чтения переменных окружения с секретами;
- нет побочных эффектов вне перечисленных каталогов;
- код возврата `0` — нарушений нет, `1` — нарушения найдены или вход не читается;
- результат воспроизводим при одинаковом входе (детерминированная сортировка, зерно
  перемешивания передается явно).

## `scripts/anonymize.py`

**Что делает.** Раздает метки `C1..Cn` кандидатам в перемешанном порядке (зерно `--seed`),
вырезает из текста строки с самоидентификацией модели и пишет карту соответствия
`label_map.json` с sha256 исходника и слепой копии.

**Читает:** каталог `--candidates` (файлы `.md`, `.txt`).
**Пишет:** каталог `--out`: файлы `C1.md` … `Cn.md`; карта `label_map.json` — в `--out`
или в `--map-out` (по умолчанию каталог `--out`).
**Сеть:** нет. **Внешние утилиты:** нет.

Два файла-кандидата с одинаковым именем без расширения — ошибка (код 1): иначе один из
кандидатов молча потерялся бы.

```
python scripts/anonymize.py --candidates candidates/ --out blinded/ --map-out . --seed 42
```

## `scripts/validate_answers.py`

**Что делает.** Проверяет ответы внешних моделей по схемам ролей: `author` (решение),
`critic` (ревью), `judge` (сравнение, эскалация), `repair` (unified diff). Достает JSON из
markdown-обертки и из текста с рассуждением перед объектом. С опцией `--check-blind`
ищет самоидентификацию модели.

**Читает:** файлы из аргументов и/или каталог `--dir` (рекурсивно).
**Пишет:** ничего; отчет идет в stdout (или JSON с `--json`).
**Сеть:** нет. **Внешние утилиты:** нет.

```
python scripts/validate_answers.py --role critic --dir reviews/ --check-blind
```

## `scripts/aggregate_votes.py`

**Что делает.** Считает рубрику `R`, взвешенную рубрику `R_w`, pairwise-оценку `P`
(Copeland) и итог `S = 0.7*R_w + 0.3*P`; применяет предфильтр (подтвержденный критический
дефект исключает кандидата), считает кворум, определяет ничью, строит лексикографическое
ранжирование (сначала проверка исполнением, потом доля скрытых тестов, потом `S`) и
предлагает вердикт: `ACCEPT`, `ACCEPT_WITH_NOTES`, `NO_CONSENSUS`, `REJECT_ALL`, `DEGRADED`.
С `--strict` возвращает код 1 при вердикте, отличном от `ACCEPT`/`ACCEPT_WITH_NOTES`.

**Читает:** JSON-файл (позиционный аргумент) или stdin при пути `-`.
**Пишет:** `--out` (по умолчанию stdout).
**Сеть:** нет. **Внешние утилиты:** нет.

```
python scripts/aggregate_votes.py votes.json --out aggregation.json --strict
```

## `scripts/normalize_reviews.py`

**Что делает.** Приводит ответы ревьюеров к виду, который считает `aggregate_votes.py`:
разбирает ответ по кандидатам (один кандидат или список `reviews` с `cid` у каждого),
отвергает неоднозначную общую рубрику без привязки к кандидату, сводит ответы одного
ревьюера из разных порядков в один отзыв на кандидата (рубрика усредняется, при
расхождении по критериям приемки учитывается худший статус, дефекты объединяются) и
**сам проставляет `consistent`**: вердикт, изменившийся при смене порядка, помечается
как ничья, а пара, у которой обратный порядок не спросили, остается без
`consistent` — и потому не засчитывается агрегатором вовсе.

**Читает:** один или несколько файлов с ответами ревьюера (`--in`, можно повторять:
разные порядки одной пары) — `--reviewer-slot`, `--reviewer-family`, `--role`.
**Пишет:** `--out` (по умолчанию stdout) — список отзывов по кандидатам;
`--notes-out` — замечания о согласованности.
**Сеть:** нет. **Внешние утилиты:** нет.

```
python scripts/normalize_reviews.py --in reviews/R1-order1.json --in reviews/R1-order2.json \
    --reviewer-slot R1 --reviewer-family qwen --out reviews/R1.json
```

## `scripts/dedup_ideas.py`

**Что делает.** Кластеризует идеи кандидатов (3-граммы тела + сходство заголовков) и
считает долю уникальных кластеров. Низкое разнообразие — признак ловушки "гомогенизация":
все модели выдали почти одно и то же, и панель перестала быть панелью.

**Читает:** каталог `--candidates` (файлы `.md`, `.txt`).
**Пишет:** `--out` (по умолчанию stdout) — `clusters.json` со списком кластеров и
предупреждениями.
**Сеть:** нет. **Внешние утилиты:** нет.

```
python scripts/dedup_ideas.py --candidates candidates/ --out clusters.json
```

## `scripts/check_run.py`

**Что делает.** Финальный гвард перед выдачей отчета: сверяет хэши заморозки (спека,
критерии, тесты, конфигурация) с фактическими файлами, проверяет целостность карты меток,
ловит саморевью и ревью внутри одного семейства, сверяет вердикт с агрегацией и кворумом.

**Читает:** каталог прогона с `run.json` и артефактами прогона.
**Пишет:** ничего; отчет идет в stdout (или JSON с `--json`).
**Сеть:** нет. **Внешние утилиты:** нет.

```
python scripts/check_run.py runs/2026-11-04T09-12-33Z-7f3a
```
